05 · Context Compaction

压缩活动 Context，不删除原始历史

旧完整 Turn 进入结构化 Memory，Todo 由事件投影，最近轮次保留原文；失败时安全降级。

06 · Session Isolation

消息、Memory 与 Todo 不串扰

Session A 和 Session B 写入独立事件流，随时切换并从各自历史继续运行。

Replay 不调用 LLM 或工具；Fork 继承分叉点之前的状态，之后父子独立演进。
